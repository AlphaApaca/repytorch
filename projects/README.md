# 端到端项目

项目用于把多个知识点串成可以展示和复述的完整成果。真正开始某个项目时再创建它的目录。

## 建议顺序

1. **FashionMNIST MLP 基线**：熟悉数据、模型、训练、验证、保存和推理的完整链路。
2. **CIFAR-10 CNN**：加入卷积、数据增强、过拟合观察和误差分析。
3. **岗位相关项目**：根据目标岗位选择真实数据与任务，重点说明问题定义和设计选择。

## 每个项目的交付要求

- `README.md`：目标、数据、运行方法、结果、局限和下一步
- 明确分开的训练、验证和推理流程
- 可追溯的超参数、随机种子和环境说明
- 指标曲线或结构化训练记录
- checkpoint 保存、加载与恢复训练
- 若干失败样本及误差分析
- 一条从新环境开始即可复现的运行命令

训练输出统一写入 `outputs/projects/<项目名称>/<运行编号>/`，目录规范见 [`outputs/README.md`](../outputs/README.md)。项目源码目录只保留代码、说明和经过筛选的展示材料。

当项目出现真实需求时，可以采用：

```text
projects/fashion_mnist/
├── README.md
├── assets/                      # 筛选后提交的曲线和结果图
├── model.py
├── train.py
├── evaluate.py
└── predict.py
```
